# python-examples

Small Python exercises I wrote while learning and practising the language. Each folder is one self-contained example, kept deliberately short so the idea it demonstrates is easy to see.

These are learning exercises, not finished software. For larger projects, see [gas-station-tycoon](https://github.com/Alan082263/gas-station-tycoon) and [ClaimsLedger](https://github.com/Alan082263/ClaimsLedger).

## What's here

| Folder | What it covers |
| --- | --- |
| `Area of Circle` | User input, the `math` module, and formatted output |
| `Reverse String` | String slicing and iteration |
| `First and Last Colours` | List indexing, including negative indexes |
| `List and Tuple Generator` | Building lists and tuples from input; how the two differ |
| `Guess the Number` | Loops, conditionals, and the `random` module |
| `Sun Stages` | Branching logic with `if` / `elif` / `else` |
| `Dog` | A first class: attributes, methods, and `__init__` |
| `Car` | Classes with state that changes through method calls |
| `Human` | Classes working together |
| `Pizza` | A small multi-file app, splitting code across modules |
| `Network Scanner` | Sockets and basic host and port checks |

`python_notes.ipynb` is my running Jupyter notebook of notes and snippets from the same period.

## Running an example

You need Python 3. Clone the repository, change into a folder, and run the script inside it:

```
git clone https://github.com/Alan082263/python-examples.git
cd "python-examples/Guess the Number"
python3 <script name>.py
```

No third-party packages are required unless a folder says otherwise.

## A note on the network scanner

Only run it against machines and networks you own or have permission to test.
